# AWS Config
- A Compliance-as-Code (CaC) framework that allows us to manage changes in your AWS accounts on a per region basis
- Change management
	- The formal process to:
		- Monitor changes
		- Enforce changes
		- Remediate changes
- Compliance-as-Code (CaC)
	- The utilization of programming to automate monitoring, enforcement and remediating changes to stay compliant with compliance programs or expected configuration
