# What is a GPU (General Processing Unit)
- A processor that is specialized to quickly render high-resolution images and video concurrently
- Suitable for Video games
- Can perform parallel operations on multiple sets of data and so are commonly used for non-graphical tasks such as machine learning and scientific computation
- Can have thousands of processor cores compared to CPU's 4-16 processor cores
- Suitable for repetitive and highly parallel computing tasks
	- Rendering graphics
	- Cryptocurrency
	- Deep learning and ML
