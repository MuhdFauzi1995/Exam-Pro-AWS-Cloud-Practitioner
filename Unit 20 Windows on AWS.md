# AWS License Manager
- Bring-Your-Own-License (BYOL)
	- The process of reusing an existing software license to run vendor software on a cloud's computing service
	- BYOL allows companies to save money since they may have purchased the license in bulk or at a time thar provided a greater discount then if purchased again
