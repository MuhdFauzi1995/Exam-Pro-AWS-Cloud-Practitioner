# What is cloud computing?
- The practice of using a network of remote servers hosted on the internet to 
	- store, manage and process data 
		- rather than a local server or personal computer

# Amazon Web Services (AWS)
- Launched in 2006 and is the leading cloud service provider in the world
- Simple Queue Service: 2004
- Simpla Storage Service (S3): March 2006
- Elastic Compute Cloud (EC2): August 2006
- In Nov 2010, all of Amazon.com's retail has migrated to AWS

# Cloud Service Provider (CSP)
![[Pasted image 20261112171931.png]]
- A company which provides Cloud Services
	- which can be chained together
	- accessible via a Single Unified API
	- utilizes metered biling based on usage
	- have rich monitoring built-in
	- have an infrastructure as a Service (IaaS)
	- offers automation via infrastructure as Code (IaC)

# Landscape of Cloud service providers
![[Pasted image 20261112172847.png]]
## Tier 1 (Top)
- Early to market, wide offering, strong synergies between servers, well recognized in the industries
- AWS, Microsoft Azure, Google Cloud Platform, AlibabaCloud
## Tier 2 (Mid)
- Backed by well-known tech companies but slow to innovate and turned to specialization
- IBM Cloud, Oracle Cloud, Huawei Cloud, Tencent Cloud
## Tier 3 (Light)
- Virtual Private Servers (VPS) turned to offer core IaaS offering, Simple and cost-effective
- Vultr, Digital Ocean, Akamai Connected cloud (Linode)
## Tier 4 (Private)
- Infrastructure as Service software deployed to run in an organization's own private data center
- Openstack, Apache CloudStack, Vmware vSphere

# Types of cloud computing
![[Pasted image 20261112190506.png]]
## SaaS (Software as a service)
- Products that are run and managed by service providers
- For Customers
## Paas (Product as a service)
- Focus on deployment and management of apps
- For developers
## IaaS (Infrastructure as a service)
- Basic building blocks for cloud IT
- Provides access to networking features, computers and data storage space
- For Admins

# Cloud computing deployment models
![[Pasted image 20261112191009.png]]
## Public Cloud
- Everything (workload or project) is built on CSP 
- AKA *Cloud-Native or Cloud First

## Private Cloud
- Everything built on company's datacenters
- AKA On-premise
- Cloud could be OpenStack

## Hybrid
- Uses both On-Premise and a Cloud service Provider

## Cross-Cloud
- Using multiple Cloud providers
- AKA multi-cloud
